# AI Engineer Resources

These are grouped to match the phases in [03-ai-engineer-roadmap.md](03-ai-engineer-roadmap.md). The links were written from memory and not checked, so a few may have moved.

## Start here (big picture)
- **The Rise of the AI Engineer** (swyx), the article that defined the role: https://www.latent.space/p/ai-engineer
- **What We Learned from a Year of Building with LLMs**, practical lessons from people who ship these products: https://applied-llms.org
- **Andrej Karpathy on YouTube.** Watch "Intro to Large Language Models" and "Deep Dive into LLMs like ChatGPT": https://www.youtube.com/@AndrejKarpathy

## Phase 1: LLM basics and APIs
- Anthropic docs: https://docs.anthropic.com
- Anthropic Cookbook (code examples): https://github.com/anthropics/anthropic-cookbook
- OpenAI docs: https://platform.openai.com/docs
- OpenAI Cookbook: https://cookbook.openai.com
- Vercel AI SDK, the best fit for Next.js: https://ai-sdk.dev
- DeepLearning.AI short courses, free and 1–2 hours each: https://www.deeplearning.ai/short-courses/

## Phase 2: RAG
- **Contextual Retrieval** (Anthropic), a very practical guide to improving RAG: https://www.anthropic.com/news/contextual-retrieval
- pgvector: https://github.com/pgvector/pgvector
- **Patterns for Building LLM-based Systems** (Eugene Yan): https://eugeneyan.com/writing/llm-patterns/

## Evals (the most important skill to stand out)
- **Hamel Husain, "Your AI Product Needs Evals"**: https://hamel.dev/blog/posts/evals/
- Hamel's blog, which has many more posts on evals: https://hamel.dev
- Eugene Yan's writing on evals: https://eugeneyan.com

## Phase 3: Agents and MCP
- **Building Effective Agents** (Anthropic). If you read only one article on agents, read this one: https://www.anthropic.com/engineering/building-effective-agents
- Anthropic's engineering blog, which covers agents, tools and context engineering: https://www.anthropic.com/engineering
- MCP docs: https://modelcontextprotocol.io
- MCP TypeScript SDK: https://github.com/modelcontextprotocol/typescript-sdk
- LangGraph: https://www.langchain.com/langgraph

## Phase 4: Production and safety
- Langfuse (tracing and evals; open source): https://langfuse.com/docs
- OWASP Top 10 for LLM Applications: https://genai.owasp.org
- **Simon Willison's blog**, the best ongoing source on prompt injection and new tools: https://simonwillison.net

## YouTube channels
- **AI Engineer** (conference talks from people building real products): https://www.youtube.com/@aiDotEngineer
- **Anthropic**: https://www.youtube.com/@anthropic-ai
- **Vercel** (AI SDK and Next.js AI demos): https://www.youtube.com/@VercelHQ
- **3Blue1Brown**, the neural network series, for intuition and not required: https://www.youtube.com/@3blue1brown

## Books
- **Chip Huyen, *AI Engineering*** (O'Reilly, 2025). This is the main book for the role.
- Chip Huyen's blog: https://huyenchip.com/blog/

## Newsletters (to stay current)
- Latent Space: https://www.latent.space
- Simon Willison's newsletter, linked from his blog above

## If you only have time for a few
Start with: Building Effective Agents → the Anthropic docs and cookbook → the Vercel AI SDK docs → Hamel's evals post → the MCP docs → Chip Huyen's book.
